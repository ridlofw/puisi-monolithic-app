=== 6. Catatan operasional dari percobaan ini ===
- `9server.sh image` (versi lama) menggantung: `curl http://localhost:5000` di shell SSM tidak dijawab (localhost dicoba lewat ::1 dulu; port 5000 hanya ditahan dockerd),
  padahal registry sehat: 127.0.0.1:5000 menjawab 200, `docker pull localhost:5000/...` normal, katalog 8 repositori utuh. Skrip diperbaiki (127.0.0.1, batas waktu,
  registry tidak dipasang ulang bila sudah ada); langkah build dijalankan manual lewat `bash 9server.sh jalankan 1 "... bangun6.sh"`.
- Registry sempat dipasang ulang (`docker service update --force`, lalu `docker stack rm registri` dan `stack deploy`) saat mencari penyebab; volume `registri_registry-data` dipertahankan
  dan semua image lama (v1, gateway v3) tetap ada.
